Wer ist verantwortlich?

David Saluda.

Wer stellt die Seite bereit?

Die Seite liegt bei GitHub Pages (GitHub, Inc.). Bei jedem Aufruf verarbeitet GitHub technische Daten in seinen Server-Logs, zum Beispiel:

  • IP-Adresse,
  • Zeitpunkt und aufgerufene Datei,
  • Angaben des Browsers (Name, Version, Betriebssystem).

Das braucht GitHub, um die Seite sicher auszuliefern. Rechtsgrundlage ist das berechtigte Interesse an einer sicheren und stabilen Bereitstellung der Seite (Art. 6 Abs. 1 lit. f DSGVO). Ich bekomme diese Logs nicht zu sehen. Wie lange GitHub die Logs speichert, legt GitHub fest.

GitHub sitzt in den USA. Die Übermittlung dorthin stützt sich auf das EU-US Data Privacy Framework bzw. auf Standardvertragsklauseln. Einzelheiten nennt GitHub. Mehr dazu: Datenschutzerklärung von GitHub.

Was die Seite nicht tut

  • Kein Tracking, keine Analyse, keine Werbung.
  • Keine Cookies zum Wiedererkennen. Die App merkt sich nur zwei Einstellungen als Cookie (Akzentfarbe, Demo an oder aus). Sie enthalten keine Zeiten und keinen Namen. Der Browser schickt sie bei jedem Abruf unter /zeiterfassung-app/ an GitHub mit. Sie und der Speicher im Browser sind technisch nötig für die App, die du selbst nutzen willst. Deshalb braucht es keine Einwilligung (§ 25 Abs. 2 Nr. 2 TDDDG).
  • Keine Schriften, Skripte oder Bilder von fremden Adressen. Alles kommt von dieser Adresse.

Wo bleiben meine Zeiten?

Alles, was du in die App eingibst, bleibt im Speicher des Browsers auf deinem Gerät. Die App rechnet dort selbst. Ich erhalte deine Daten nie.

Daten verlassen das Gerät nur, wenn du es selbst einschaltest:

  • Synchronisierung über dein eigenes GitHub-Repo: Die App spricht dann mit api.github.com und deinem Repo. Dorthin gehen nur verschlüsselte Sync-Dateien. Das Token bleibt auf deinem Gerät.
  • Sicherung als Datei: Die App erstellt eine Datei auf deinem Gerät. Wohin du sie legst, entscheidest du.

Links zum Wiki und zu den Releases öffnen GitHub erst, wenn du sie antippst.

Prüft die App auf neue Versionen?

Ja, aber nur bei ihrer eigenen Adresse, also bei dieser Seite. Beim Öffnen, beim Zurückkehren in die App und alle 15 Minuten lädt der Browser das kleine Dienst-Skript der App neu und vergleicht es. Die App fragt dafür nicht bei der GitHub-API und sendet keine Daten von dir mit.

Welche Rechte habe ich?

Du hast das Recht auf Auskunft, Berichtigung, Löschung, Einschränkung der Verarbeitung, Datenübertragbarkeit und Widerspruch. Du kannst dich auch bei einer Datenschutz-Aufsichtsbehörde beschweren.

  • Server-Logs: Die hat nur GitHub. Wende dich dafür an GitHub (siehe oben).
  • Daten der App: Die löschst du selbst: in der App unter Einstellungen → Module und Profile → Alles zurücksetzen, oder ganz, indem du im Browser die Website-Daten dieser Seite löschst.
